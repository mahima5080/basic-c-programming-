# C Programming — Week 1 Assignment & Mini Project

## 📌 Project Overview
This repository contains solutions to the **C Programming Week 1 Assignment** covering syntax, variables, conditional statements, and loops, along with a Simple Calculator mini-project using switch-case.

## 📁 Repository Structure
* `1_hello_world.c`: Prints "Hello World."
* `2_sum_two_numbers.c`: Read two numbers from user input and print their sum.
* `3_even_odd.c`: Checks if an input integer is even or odd.
* `4_fibonacci.c`: Displays the Fibonacci series up to a user-specified 'n' terms.
* `mini_project_calculator.c`: An interactive, menu-driven command-line calculator.

## 🚀 How to Compile & Run
To compile and run any of the files locally, use a C compiler like GCC:

```bash
# Example: Compiling the Calculator Mini Project
gcc mini_project_calculator.c -o calculator
./calculator
